Let AI assistants like Claude, ChatGPT and Codex use Video Downloader for you. Ask in plain words, and the assistant downloads videos, clips, audio, transcripts and frames straight to your computer.

This works through MCP (Model Context Protocol), the standard way to give an assistant new tools. It runs on your PC. There's no account or API key, and nothing is uploaded anywhere.

Try saying

  • “Download this in 1080p: https://www.youtube.com/watch?v=…”
  • “Save the part from 1:20 to 1:45 as a clip I can edit in Premiere.”
  • “Get the transcript of this video and summarize it in 5 bullet points.”
  • “Grab the frame at 2:03 and tell me what's on screen.”
  • “Save all the photos from this Instagram post.”

Files are saved to {% if mcp.os == 'windows' %}Downloads\Video Downloader{% else %}Downloads/Video Downloader{% endif %} unless you ask for another folder.

{% if c.codex %}✓ Already connected on this PC{% endif %}
  1. Open {% if mcp.os == 'windows' %}%USERPROFILE%\.codex\config.toml{% else %}~/.codex/config.toml{% endif %}. The Codex app, CLI and IDE extension all share this file.
  2. Add this at the end: 
    {{ mcp.codex }}
    tool_timeout_sec gives long downloads up to 15 minutes. Without it, Codex stops a tool after 60 seconds.
  3. Restart Codex, or start a new chat. To check, run codex mcp list.

ChatGPT can only connect to MCP servers on a public https:// address, so this takes a few more steps and a free tunnel.

  1. Start the server in HTTP mode. It serves http://127.0.0.1:5758/mcp: 
    {{ mcp.http }}
  2. Install cloudflared{% if mcp.os == 'mac' %} (brew install cloudflared){% elif mcp.os == 'windows' %} (winget install Cloudflare.cloudflared){% endif %}, then open a tunnel in a second terminal: 
    {{ mcp.tunnel }}
    It prints an address like https://something.trycloudflare.com.
  3. In ChatGPT, go to Settings → Apps & Connectors → Advanced and turn on Developer mode. Then click Create, enter that address followed by /mcp, and choose No authentication.
  4. In a chat, turn on the connector from the + menu, then ask away.

While the tunnel is open, anyone who has its address can use these tools on your PC, because it has no login. Close both windows when you're done. Files are always saved on your PC, not sent to ChatGPT.

What the assistant can do

ToolWhat it does
get_video_infoTitle, length, every quality with its file size, audio options and transcripts, or the photos of a post.
download_videoMP4 in any quality, whole or as a clip. It can make an editor-friendly H.264 file, with frame-exact cuts as an option.
download_audioMP3 or M4A, of the whole video or just a part.
get_transcriptThe captions as text, with or without [m:ss] times, in any language the video has.
capture_frameA full-resolution PNG or JPG at any moment. The assistant can also see the picture.
download_thumbnailThe largest thumbnail, as the original file or as JPG or PNG.
download_imagesEvery photo and video of an Instagram, X, Reddit, Pinterest or LinkedIn post.

Good to know

  • You don't need to open the app first. The assistant starts the tools when it needs them.
  • If you move the app folder, copy the settings from this page again so the path is right.
  • Logins for private posts (the Login settings in the classic interface) are used by the assistant too.
  • Only download content you own or have permission to save. See the Terms of Service.
